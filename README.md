# Senior_project
2026_Fall_ED2 group project with Amir Farrukh, Juan Pena, Matthew Ishibashi, and Tyler Garrett



IMMERSANET focuses on creating a ML model to detect different animal species inside a certain region using their audio files at a high accuracy. This prototype is for the frontend where users can view readings after our model has analyzed the audio to filter by name and confidence while also having the ability to generate a report.   

https://seniorproject-bexs3gvksenf44rxhfkimi.streamlit.app/#table

The application servers as a way for researchers to easily view aquatic animal data from the model after inputting it.
